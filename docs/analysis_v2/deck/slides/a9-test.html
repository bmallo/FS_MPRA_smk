Step A9 · How the test and its check work

Compare like with like, count clones honestly, then test the test on WT

1 · Effect

Each SNV molecule is set against WT molecules of the same labeling. D = how far the SNV's molecules sit from that expectation, averaged.

Example: an SNV molecule with labeling 0.42 at an adenine WT leaves unmarked 70% of the time at that labeling contributes (unmarked? 1 : 0) − 0.70.

→

2 · Uncertainty

Chance among molecules, plus chance among clones. The clone part uses τ² estimated from thousands of WT clones, so it stays right when an SNV has only a few big clones.

z = D ÷ its standard error; features with < 10 molecules, < 3 clones or < 5 expected rare events are not tested.

→

3 · Check on WT only

For each real SNV, 4 pseudo-variants: WT clones drawn to the SNV's clone sizes, tested against the remaining WT. Every call there is false.

Targets: 4–6% at p < 0.05; λ 0.9–1.1; ≥ 1 BH discovery in ≤ 5% of pseudo-variants. The same draws give each SNV's MDE.

MPRA convention: barcodes (clones) as replicates against a common WT (mpralm, Myint 2019; MPRAnalyze, Ashuach 2019); empirical null from the data themselves (Efron 2004)

Random-effects variance of D: Σ_m p(1−p)/n² + τ² Σ_c (n_c/n)² for the SNV, and per WT labeling stratum p(1−p)/N_s + τ² Σ_c (n_c/N_s)², weighted by the SNV's stratum shares. τ² per feature from a one-way random-effects moment estimator on WT clones (tested to recover simulated values). p from the normal distribution.
