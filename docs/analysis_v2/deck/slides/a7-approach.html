Step A7 · What an edit does to the caller by itself

If no protein changed, how much would an SNV still move the footprint calls?

Why

The caller reads only reference A/T where the read matches. An SNV at an A/T (including an A↔T swap) removes that base from the variant's evidence. Nearby adenines can also change context, which changes how well Hia5 marks them. Either can move calls with no change in binding.

What we did

Took WT molecules (HepG2 run 3: 138,770; HEK293T: 42,952; classes C and M), applied each edit in silico and re-called them with the same scan, emissions and thresholds. Compared each with the same molecules unedited. Edits: one dropped A/T, each variant's agreed mask, the ±5 bp mask, and a naked-DNA context model.

What we found

  • Dropping one A/T moves calls by a median of 0.9–1.0% of C molecules (up to 4–5%), mostly within ±20 bp.
  • The agreed mask costs a median 1.4–1.5%; the ±5 bp mask about twice that.
  • The drop explains only 15% of the v1 A/T-loss offset (29% with the context model).
