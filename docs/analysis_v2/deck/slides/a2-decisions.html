The designed indels are the biggest opportunity: about 1,200 molecules per variant across 146 deletions and 637 insertions. They need the same informative-base and in-silico checks (A4, A7) as SNVs, because a deletion can remove an A/T and an insertion can add one. Kircher et al. 2019 also measured activity for deletions.
