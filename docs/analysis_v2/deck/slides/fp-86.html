Mechanism: the variant base is never read, so a call that ended at 86 in WT now ends at 85: position 86 alone loses coverage. All three alleles drop the same base, hence the consistent spike.

Masking hides the same adenines in WT and variant, so it cannot create a difference by itself; a real chromatin change survives it, minus the evidence those adenines carried. Here that cost is real: masking 85-86 in WT alone lowers coverage over 78-86 by 1.2-4.9 points.

Source: explorer_v4 chunks, a7_snv_edits/HepG2_run3/artifacts.npz, a10_effects · the explorer now shows the masked test difference by default

The explorer's earlier "WT − variant" footprint track was the raw difference of the two coverage tracks, so it carried this artifact even though the statistics did not. That is fixed: the default is now the A10 test with the chosen mask, with ±1.96 SE bands, and "as read" is a labelled option.
