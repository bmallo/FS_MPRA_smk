Step A8 · Size and boundaries

Called lengths are within a few bp, so size-class edges blur

Newly detected calls are 0–4 bp longer than the spike up to 80 bp, 6–14 bp at 147 bp. Calls end on the nearest observed adenine.

So a 20-bp footprint is often called 18–22 bp and lands in either the 10–19 or 20–40 class. Spikes in mid-class sizes (15, 30, 60) stay in class 62–66% of the time; at class edges (10, 20, 40, 80) only 17–43%.

Source: a8_confidence/spikes/*/spikes.tsv · C molecules, position-specific emissions · left = median net size-correct / median net detection

Size classes are from common.py (10–19, 20–40, 41–80, 81+). A footprint near a class edge is split between two classes by a couple of bp of boundary error, so per-class counts are not independent measurements of different proteins.
