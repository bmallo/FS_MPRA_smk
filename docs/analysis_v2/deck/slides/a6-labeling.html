The naked control is another plasmid called with ft predict-m6a 0.5.4, so only the position of its peak is comparable, not its exact shape. The element's m6A rate relative to the backbone rises smoothly with labeling (median 1.0 in the lowest C bin to 1.26 in M), and the element profile in mid C (0.4–0.6) correlates with M at r = 0.97–0.99. So M differs from upper C in degree, not in kind.
