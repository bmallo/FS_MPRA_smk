Step A7 · Terms used in this section

How a footprint call is made, and what an edit changes

TermMeaning
Marked / unmarked adenineAn A/T with or without an m6A call. Marked = Hia5 reached it (evidence nothing was bound); unmarked = evidence something may have been bound.
Running scoreThe caller walks along each molecule, adding a positive score at each unmarked adenine and a negative one at each marked adenine (sizes from the emission table).
Footprint callA stretch whose running score rises above 5. Its length sets the size class: 10–19, 20–40, 41–80 or 81+ bp.
Coverage% of molecules with a call covering a given base.
Dropped adenineAn A/T the caller ignores because the read does not match the reference there: what happens at the edited base of an SNV at an A/T (A↔T swaps included) or a deletion.
Re-contexted adenineA neighbour whose A-run context the variant changes (e.g. AAAAA → AAGAA); Hia5 marks it differently. Chemistry, not the caller.
ArtifactChange in coverage between WT molecules edited in silico and the same molecules unedited: no biology can differ.
Mask / mask costRemove the same adenines from variant and WT before comparing, so the artifact cancels. Cost = how much that removal changes the WT calls.
Largest changeFor one edit, the biggest coverage change at any element position and size class (% of molecules).

Caller: plasmid-LLR, min LLR 5, drawdown 25 · emissions from WT M ("accessible") and U ("protected") molecules (A6)

The running score is a log-likelihood ratio: an unmarked adenine adds ln((1 − p_p)/(1 − p_a)), a marked one adds ln(p_p/p_a), where p_a and p_p are that adenine's marking rates in M and U molecules. A segment also closes when the score falls 25 below its peak (drawdown), so long arrays are split.
