What runs 1–2 can do

Thousands of WT clones support a WT footprint reproducibility test (A8), and motif-level tests that pool SNVs. Per-SNV tests are not possible: one clone dominates each SNV.

A barcode rule problem for A3

A barcode is rejected if any read shows a different genotype. Deep barcodes (hundreds of reads) almost always carry one stray read, so 57% of run 1’s eligible molecules fall into “collision”.

Source: a2_accounting/clone_depth_by_run.tsv; a2_ledgers/run1/barcodes · barcodes = distinct N15 sequences on eligible molecules

Example from run 1: barcode AGGCTTTGACGACAC has 280 reads of one SNV, 3 WT reads and ten single reads of other variants; the current exact rule marks it a collision. Standard MPRA assignment tools use a majority or fraction threshold instead. In run 3 collisions are 3% of eligible molecules because barcodes are shallow. Molecules are not dropped for barcode reasons (each becomes its own resampling cluster), but treating hundreds of reads of one clone as independent would understate uncertainty, so A3 must fix this before any run-1 statistics.
