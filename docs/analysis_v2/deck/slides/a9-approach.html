Step A9 · Statistical framework

Which variant-vs-WT test keeps its error rate, and how big an effect can each SNV show?

Why

Molecules from one barcode clone are not independent, labeling differs between molecules, and an SNV's molecules can sit in a few clones. A test that ignores this calls effects that are not there; a test that over-corrects misses real ones.

What we did

Extracted every analysis-ready WT and SNV molecule with its clone and labeling. Built fake variants from WT clones with each real SNV's clone sizes (no effect exists) and tested them. Compared SNV and WT molecules on labeling, passes and strand. Computed each SNV's smallest detectable effect. No variant chromatin data were used.

What we found

  • The prespecified clone test fails; a random-effects test (clone variance learned from WT) keeps ~5% false positives in HepG2.
  • SNV and WT molecules are as alike as chance allows (HepG2).
  • HepG2: ~2.5 points per adenine detectable; HEK293T: half the SNVs untestable.
