Step A8 · One spike, two real molecules

A planted footprint stands out on a marked molecule and vanishes on an unmarked one

Left (labeling 0.72): marked adenines keep the score near zero. Blocking 20 bp lifts it past 22, and a 17-bp call appears: from the first to the last unmarked adenine in the stretch. Detected.

Right (labeling 0.06): almost nothing is marked, so the whole window is one 452-bp call before the spike. Blocking 20 bp changes nothing: already called.

This is why net detection is 95–98% in M but 11–19% in low-labeled C, and why footprint calls use molecules with labeling ≥ 0.2.

Source: tools/analysis_v2/a8_example.py · HepG2 run 3 (A6 rows 116241 and 12602), run-3 fold-A emissions · spike reference 1310–1329

Molecules were picked in a seeded random order as the first M molecule not called over the spike before and detected after, and the first low-labeled C molecule already called there: the typical case in each group, not the only one. The window shows ±50 bp around the spike centre; call lengths are the full calls.
