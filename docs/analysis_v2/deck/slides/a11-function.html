Reading: among alleles at the same position, one that raises the unmarked fraction across the element by 1 point has ~0.35 log2 (~22%) lower expression. The link holds without the 17 Repeat 3 SNVs (−0.32), without all 29 element-wide SNVs (−0.32) or without positions 140–156 (−0.28).

Expression comes from a separate experiment (Kircher 2019), so this is a correlation across SNVs, not a mechanism. Measurement error in the chromatin estimates would weaken, not create, the slope. Without the position term the slope is −0.67 (both sources agree).
