Step A8 · Repeatability of WT profiles

Clone halves agree within sampling; HepG2 runs 1 and 3 differ

z = difference ÷ its expected sampling error (clone bootstrap). If two profiles differ only by sampling, SD(z) ≈ 1 and ~5% of positions have |z| > 1.96.

Clone halves (all endpoints, 3 runs): SD(z) 0.36–1.18; 0–9% of positions beyond 1.96.

Run 1 vs run 3: SD(z) 1.7–13.7; 45–87% of positions beyond 1.96. Unmarked fraction differs by 2.4 points per adenine on average; 20–40 bp coverage is 0.67% in run 1 vs 0.96% in run 3.

Labeling was matched by strata, so the gap is the reaction (time, Hia5 dose), Jasmine version, or both.

Source: a8_confidence/repro/summary.tsv, positions.tsv.gz · C molecules, standardised to run 3's labeling mix · each run's emissions rebuilt from its own WT M/U

Clones: HepG2 run 3 92,123 (12% read subsample, mostly one molecule each), run 1 5,698, HEK293T 989 (bottlenecked). With so few molecules per clone in run 3, its halves test molecule-level sampling more than clone effects; run 1 and HEK293T test clones more directly. Run 2 (2,813 WT molecules) was not tested.
