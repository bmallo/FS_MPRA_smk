# HepG2 replicate-3 pilot — 2026-10-14

The current result bundle is under `results/pilot_20261014/`. The reviewed
interactive artifact is `HepG2_rep3/dashboard_reviewed/index.html`; open that
file in a browser. The scientific overview is in `HepG2_rep3/plots/overview.pdf`
and `overview.png`. These generated files are excluded from Git.

## Scope and results

- Library catalog: 1,417 unique sequences after collapsing equivalent oligos,
  including WT and all 633 designed SNVs. The two published MPRA sources remain
  separate, with allele-aware joins and source provenance.
- Sampling: deterministic 1% selection from the entire genotype ledger,
  seed 42; 87,385 selected molecules, all matched to source metrics.
- Measurement: 28,415 WT/SNV molecules pass the initial full-plasmid,
  polymerase-pass, exact mutable-sequence, and annotation requirements.
- WT: 13,549 measured molecules. SNVs: 631/633 have evidence; 603/633 have
  at least 10 molecules. Median SNV coverage is 22; range is 0–94.
- All per-track denominators reconcile to measured molecule counts, and
  methylation/MSP histograms reconcile to their eligible populations.

No methylation-based exclusion is applied. The analysis currently summarizes
the 211-bp mutable element, not a user-confirmed full promoter interval. The
small-footprint track uses existing TF-track calls of 10–60 bp; MSP coverage is
a caller-derived accessibility proxy. The common-site summary excludes the
substituted position ±2 bp from both variant and WT as a sensitivity readout.
There are no p-values, confidence intervals, or claims of biological discovery
from this pilot. Published MPRA p-values retain their source meaning.

## Annotation correction

FiberHMM's sparse MA writer omits empty track sections. The caller invocation
and installed `fiberhmm/io/ma_tags.py:format_ma_tag` establish that the replicate-3
output evaluated nuc, msp, and tf tracks. Its manifest therefore explicitly
declares that contract. Omitted evaluated tracks contribute measured zero:
3,712 nuc, 2,636 tf, and 1,656 msp omissions. One absent MA annotation remains
missing and is excluded from measurement.

The initial `results/redesign/` measurement bundle treated those omissions as
missing and is superseded. Do not use its profiles or denominators. No original
experimental files were changed. Other samples still need an equivalent
format/protocol check before declaring the same annotation contract.

## Validation

- Ten Python tests pass, including a synthetic pipeline with a reverse-strand
  WT, methylation extremes, sequence/coordinate checks, indel equivalence,
  missing versus empty tracks, duplicate joins, provenance failures, and HTML
  data-embedding safety.
- JavaScript checks pass for null-versus-zero handling, gaps in profiles,
  allele joins, schema rejection, small p-value display, and the real bundle's
  634 WT/SNV records.
- A complete synthetic Snakemake run passes through catalog, molecule import,
  measurement, and dashboard export using one core.
- The real exported dashboard renders in headless Firefox; the static
  PNG/PDF overview was generated and the PNG visually inspected.
- Real-browser interaction checks pass for allele selection/search, WT and
  next/previous navigation, difference profiles, coverage controls, unmeasured
  alleles, and overview metric changes (`tests/browser_smoke.js`).

Commands and parameter definitions are in [pilot_usage.md](pilot_usage.md).
Substantive processing ran inside the existing Slurm allocation using one
processing thread. The viewer is self-contained and requires no hosting.
