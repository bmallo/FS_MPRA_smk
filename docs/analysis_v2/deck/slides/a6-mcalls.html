Step A6 · What the existing calls already show

The LLR already calls TF-sized footprints in M at the same spot

At oligo 60–86, 6.8–7.7% of held-out M molecules carry a 20–80 bp call, more than C (3–4.8%). Elsewhere in the element M is mostly below 1%.

So the caller-free test and the caller agree on where M is not naked. This holds even though the M emissions already absorb part of it.

Source: results/llr_vs_fiberhmm_20261026 calls (fold-A emissions, min LLR 5) · a6_proxies/summary/m_calls.tsv · HepG2 run 3 only

M molecules here are the held-out half (fold B) of the 93,030 M molecules used to build emissions, so they were not used to fit the table. C molecules show fewer 20–80 bp calls at this spot partly because more of them carry longer (nucleosome-sized) calls over it. Calls are 1-based inclusive in the parquet; converted here.
