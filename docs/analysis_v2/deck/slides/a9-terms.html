Step A9 · Terms used in this section

How one SNV is compared with WT

TermMeaning
Endpoint E1At each element adenine: is it unmarked? No caller involved. Molecules with labeling > 0.01.
Endpoint E2At each element position: is it covered by a footprint call of a given size (10–19, 20–40, 41–80, 81+ bp)? Molecules with labeling ≥ 0.2 (A8).
Effect DFor the SNV's molecules: observed − expected, where "expected" is the WT rate among WT molecules of the same labeling (strata of 0.05). Labeling differences cancel by design.
Clone variance τ²How much clones differ from each other beyond molecule-to-molecule chance, learned from the many WT clones.
Pseudo-variantA fake SNV made of WT clones with the real SNV's clone sizes. No effect exists, so a good test calls ~5% of them at p < 0.05.
λMedian test statistic ÷ its expected value with no effect. 1 = right; > 1 = too many false calls; < 1 = too cautious.
BH false discoveryShare of pseudo-variants with ≥ 1 position called after Benjamini–Hochberg at 5% across that SNV's positions. Target ≤ 5%.
SMDStandardised mean difference between SNV and WT molecules in a covariate (labeling, passes, strand).
MDEMinimum detectable effect: the smallest true difference found 80% of the time at p < 0.05.

Primary variance of D = binomial chance on both sides + τ² × Σ(clone share)² for the SNV and for WT. With one dominant clone, Σ(clone share)² ≈ 1, so the clone term carries the full clone-to-clone uncertainty instead of vanishing.
