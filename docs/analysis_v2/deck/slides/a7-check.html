The re-call reproduces the existing LLR calls

Unedited molecules, 20–80 bp calls: C 1.65% (existing 1.66%), M 1.46% (existing 1.43%) averaged over the element. Profiles agree at r = 0.999 (C) and 1.000 (M).

So the edited runs differ from the existing calls only by the edit. The molecule sets differ (A6 WT set vs the LLR comparison set), so close but not identical levels are expected.
