Proposed rule

A clone is accepted when ≥ 90% of its ≥ 2 full-length qualified reads share one genotype. Reads that contradict a confident clone are dropped as likely misreads. Singleton barcodes stay in, each as its own clone.

Source: a3_genotypes/assignment_rules.tsv · run-2 majorities include partial reads here; the proposed rule uses full-length reads only

The change matters most for run 1, where clones are deep (hundreds of reads) and one stray read used to reject the whole clone. In run 3, clones are shallow and the change adds only 0.4 points. A 90% fraction threshold follows standard MPRA barcode-association practice of requiring a dominant genotype rather than unanimity; it is set here from read properties, before any effect is examined.
