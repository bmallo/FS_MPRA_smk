# HepG2 replicate-3 ledger — 2026-10-16

This run generates a complete barcode/genotype ledger from the existing
replicate-3 alignment using the exact-barcode baseline selected after benchmarking.
It retains every primary plasmid alignment, including unresolved observations,
and preserves original molecule IDs.

The run directory is `results/rep3_ledger_20261016/`. See the
[workflow and field definitions](rep3_ledger.md) for the reproduction command.
The configuration, code snapshot, regression validation, tests and workflow log
are retained with the results.

These categories describe observations and configured QC. An off-design sequence
does not by itself establish a genuine unintended construct: sequencing errors,
complex sequence variation, or alignment/extraction effects can also cause it.
The full observed sequence is retained for future investigation. The analysis
cohort deliberately excludes designed insertions/deletions, whereas genotype
and barcode evidence tables retain them.

The complete traversal covered 8,729,367 indexed plasmid alignment records and
matched the BAM index count. Extraction used 88 bounded chunks and took about
12.6 minutes with three workers plus a reader in the four-CPU allocation.
Genomic/unmapped reads are outside this plasmid-ledger entrypoint.

## Barcode assignments and variant coverage

The workflow completed all five steps. The final ledger contains 8,715,827
molecules, of which 4,529,384 have supported barcode assignments. The headerless
MPRAsnakeflow export contains 986,680 unique barcode-to-element mappings.
Among the 2,594,368 current analysis-eligible WT/SNV molecules, 2,102,906 have
supported barcode assignments: 985,264 WT and 1,117,642 SNV molecules.

| Molecule assignment status | Count |
|---|---:|
| Supported | 4,529,384 |
| Insufficient support | 3,503,445 |
| Genotype unresolved | 428,766 |
| Barcode collision | 171,250 |
| Genotype disagrees with barcode assignment | 82,982 |

All 633 designed SNVs have analysis-eligible molecules, and 632 have at least
one supported barcode. The median SNV has 1,955 eligible molecules and 441
supported barcodes; 630 of 633 SNVs have at least 50 supported barcodes.
WT has 1,243,891 eligible molecules and 268,283 supported barcodes.
These are descriptive coverage measures, not evidence of statistical power or
independent biological replication.

Three SNVs have particularly limited coverage in the analysis-eligible cohort:

| Variant (oligo 1-based position) | Eligible molecules | With supported assignment | Supported barcodes |
|---|---:|---:|---:|
| 160A>G | 1 | 0 | 0 |
| 222T>C | 2 | 2 | 1 |
| 176G>A | 24 | 8 | 4 |

These positions refer to the original oligo, not mutable-element-relative or
genomic coordinates. The broader sequence-qualified cohort has 9, 19, and 27
molecules respectively, so these variants already have low coverage before
the full analysis filters. They should remain flagged in subsequent plots
and statistical analyses.

## Validation

The optimized extractor reproduced all observation fields for the 87,618-read
benchmark. Exact barcode maps, molecule assignments, assignment exports and
existing coverage fields matched the full-depth benchmark baseline. All 38 tests
passed, including sparse/repeated modification groups and duplicate IDs spanning
different chunks.

The final ledger is published only after the observation/assignment join checks
every read ID, observed barcode, assigned genotype, and molecule count. Barcode
ingestion enforces global read-ID uniqueness; rejected assignments remain present
with empty accepted-barcode and accepted-genotype fields.
