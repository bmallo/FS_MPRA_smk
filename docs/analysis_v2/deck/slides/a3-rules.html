Step A3 · How calls are made today

Each read carries its own genotype; the barcode only names its clone

Genotype (per read)

Cut the 211-bp element between exact 4-bp anchors in the alignment

Exact match to one of 1,417 designed sequences (WT, SNV, 1-bp indel)

Every element base ≥ Q20; passes ≥ 10, read quality ≥ 0.99

Clone (per barcode)

Read the N15 barcode at its fixed position; every base ≥ Q20

Group reads by exact barcode; no error correction (benchmarked 16 Oct)

Accept if ≥ 2 qualified reads and no read shows another genotype

The shaded rule is the one this step changes. Methylation and footprints are never used to call a genotype or a clone.

Code: fsmpra/processing.py (extract), fsmpra/barcodes.py (assign_barcodes) · settings: results/rep3_ledger_20261016/config.json

Homopolymer indels collapse: deleting any base of a run gives the same molecule, so 2,115 designed oligos become 1,417 distinct sequences (WT 1, SNV 633, DEL 146, INS 637). Barcode error correction (quality-directional, Pacybara) was benchmarked on 16 Oct and not adopted because it gained under 1% of reads and made some questionable merges.
