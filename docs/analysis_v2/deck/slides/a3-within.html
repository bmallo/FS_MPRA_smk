In runs 1–2, partial reads disagree with their clone far more often (at 30+ passes, 3.9% of run-1 and 15% of run-2 reads), but full-length reads behave like run 3 (0.4–1.1% one edit, about 0.1% unrelated). Partial reads therefore should not be recovered, which reverses the A2 proposal for them. The deletion figure is an average; misreads concentrate in long homopolymers, so the most exposed deletions get a per-variant estimate before effects are tested (A10).
