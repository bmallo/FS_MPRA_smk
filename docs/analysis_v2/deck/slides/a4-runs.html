This answers part of your question 2: the low marking of A-runs in our M molecules is not evidence that M is protein-bound, because a truly naked plasmid shows it too. Whether the enzyme or the m6A caller causes it cannot be separated with these data, and for the analysis it does not need to be: both bias every molecule the same way. The naked control is a different plasmid sequenced with an older caller (Jasmine 2.2.0 vs 26.1.3 for HepG2 run 3), so only the shape is compared, as rates relative to isolated adenines in each table.
