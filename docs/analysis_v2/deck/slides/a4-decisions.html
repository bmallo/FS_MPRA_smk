Decided after A4: symmetric masking is primary. For each variant, the same bases (the edited base when the caller loses it, and adenines whose run context changes) are removed from its molecules and from WT before calling. Sensitivity checks: a ±5 bp mask, and A ↔ T swaps read from the bottom strand. Scoring each variant on its own sequence waits for B1.

Not a concern: A/T spacing. The smallest detectable footprint is at most 11 bp at every position, so nothing in the element is hidden from a TF-sized footprint for lack of A/Ts. The concern is the uneven strength of evidence and how variants change it. The masking option is symmetric (the same bases are removed from WT and variant), so it cannot create an effect, but it costs evidence close to the variant, where effects are expected.
